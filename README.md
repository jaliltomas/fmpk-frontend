# FMPK - Fucking Matching Problem Killer

Aplicación web construida con [Vue 3](https://vuejs.org/) (Options API), [Vite](https://vitejs.dev/) y [Tailwind CSS](https://tailwindcss.com/) para gestionar sesiones de matching y estadísticas básicas.

## Requisitos

- Node.js 18+

## Scripts disponibles

```bash
npm install    # Instala dependencias
npm run dev    # Inicia el entorno de desarrollo
npm run build  # Genera la build de producción
npm run preview # Previsualiza la build de producción
```

## Características

- Layout tipo dashboard con header fijo y sidebar de navegación.
- Gestión de sesiones con persistencia en `localStorage`.
- Vistas de Home y Sesiones conectadas con Vue Router.
- Estilos modernos usando Tailwind CSS.
